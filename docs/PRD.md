# 工程照片整理器 V1.0 PRD

## 目標

讓工程人員在沒有網路、沒有登入的 Windows 電腦上，把大量現場照片整理成可交付的工程照片報告。

## P0 功能

- 建立／開啟 `.sprj` 工程。
- 建立工程項目並上下排序。
- 每個項目支援單一欄位、施工前／中／後、改善前／後與自訂欄位。
- 匯入 JPG、JPEG、PNG、WEBP、BMP；保留原圖並建立縮圖。
- 未分類區、單選／Ctrl 多選／Shift 範圍選取。
- 拖曳至欄位、欄內排序、右鍵移至任一項目或欄位。
- 編輯照片說明、施工位置、是否輸出。
- 自動儲存 SQLite；匯出 PDF／Word／Excel。

## P1／P2 預留

分類建議介面、EXIF 擴充、品質檢查、範本、相似照片偵測、AI 視覺模型、原始照片包與浮水印。

## 不變規則

原始照片永不被覆寫；人工分類優先於自動建議；前中後不能寫死在資料庫；輸出只讀取預覽圖與資料模型。
