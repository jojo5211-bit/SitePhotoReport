# 手機版更新紀錄

## 1.1.3（2026-08-20）

- 更新 Flutter 新版表單、選項與拖曳排序 API，降低日後 SDK 升級造成的相容性風險。
- 相片欄位排序改用新版回呼，拖曳後的位置不會因 API 索引差異而偏移。
- 維持快速分類失敗保留原照片、舊工程延後維護、PDF 多頁預覽／輸出與拍照保存手機相簿等穩定性修正。

## 1.1.2（2026-08-12）

- 直接在工程項目內拍攝照片時，除了保存到工程專案，也會同步保存一份到 Android 手機內建相簿。
- 若使用者拒絕相簿權限，工程照片仍會正常保存；畫面會提示相簿副本未建立。
- 新增相簿權限處理與照片保存結果提示。

## 1.1.1（2026-08-12）

- 修正欄位內直接拍照／匯入後畫面不即時更新；每張照片完成保存後立即重新整理目前欄位。
- 加入載入請求序號，避免工程初次載入較慢時，舊查詢結果覆蓋剛加入的照片。
- 相機／相簿來源先以 `flush` 寫入工程 `originals/`，再用資料庫交易寫入照片與欄位關聯，重新開啟工程仍可看到。
- 匯入過程顯示「照片載入中，已加入的照片會即時顯示」，避免誤以為匯入失敗而重複操作。

## 1.1.0（2026-08-11）

- 修正快速分類將照片放入欄位時的資料庫唯讀錯誤處理，失敗照片會保留在原畫面並顯示原因。
- 修正 PDF 預覽與輸出多頁內容，避免只顯示第一張或只輸出單頁。
- PDF 輸出完成後可依設定開啟檔案、分享或交由其他應用程式處理。
- 修正欄位管理、照片跨欄位拖曳與排序的狀態同步。
- 編號改為共用 `NumberBadge` 渲染，避免列表出現重複編號；支援取消目前欄位編號。
- 未分類照片讀取 EXIF 拍攝時間，依日期排序並顯示日期分隔線。
- PDF 支援工程基本資料封面、模板、每頁照片數與直立／橫向自動版面。
- 首頁加入專案管理、備份與刪除入口；輸出與預覽加入載入狀態。
- 改善 Android 系統導覽列遮擋畫面時的安全區域處理。

## 1.0.3（2026-07-27）

- 編號顯示只繪製一次，保留位置、顏色、大小與透明底設定。
- 新增個別欄位取消編號。
- 未分類照片依拍攝日期由早到晚排列，跨日顯示日期分隔線。
- 舊工程開啟時會回填缺少的 EXIF 拍攝時間。

## 1.0.0（初始版本）

- 建立工程、項目與照片欄位。
- 手機拍照／匯入、照片分類、排序、編號與報告輸出。
