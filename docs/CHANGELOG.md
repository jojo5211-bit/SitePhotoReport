# 版本更新紀錄

## 0.8.1（2026-08-21）

- 照片匯入改為背景處理，批次匯入與外部資料夾拖曳時主畫面保持可回應，並顯示目前進度。
- 開啟舊工程時先顯示工程內容，再於背景重建缺少的縮圖與預覽圖，避免大量照片讓程式看起來像當機。
- 加強單張照片匯入錯誤處理；損壞、無法讀取或檔案暫時不可用時只略過該張，不中斷整批匯入，也不留下半成品。
- EXIF 拍攝時間統一為可排序格式，匯入後未分類日期排列更穩定。
- 新增輸出前檢查：提醒未分類照片、未確認 AI 建議與缺少照片檔案；沒有任何可輸出的照片時會阻止輸出。
- 增加 SQLite 忙碌等待時間，降低背景工作與工程資料庫交接時的鎖定錯誤。
- 完成穩定性驗證：Python unittest 32 項全數通過。
- 完成大量照片壓力驗證：500 張 1280×960 測試照片匯入 500/500，縮圖與預覽重建 500/500；背景工作期間主畫面事件仍持續運作。
- 產生可獨立執行的 Windows portable 版本 `SitePhotoReport_0.8.1`，並保留所有舊版本。

## 0.8.0（2026-08-11）

- PDF 改為每個項目／欄位都從新頁開始，避免不同欄位被塞在同一頁中間或下方。
- 同一欄位的多張照片仍會在自己的頁面內排列；超過每頁上限時才使用續頁。

## 0.7.9（2026-08-11）

- 修正照片較少的項目／欄位仍強制各佔一頁，造成頁面大量留白的問題。
- 依頁面剩餘空間自動接續下一個項目／欄位；仍遵守每頁最多 1／2／4／6 張照片設定。

## 0.7.8（2026-08-11）

- 修正 PDF 項目／欄位標題可能單獨落在頁面底部、照片被推到下一頁的問題。
- 項目／欄位標題會與第一列照片保持在同一頁；同一欄位照片跨頁時才顯示續頁標題。

## 0.7.7（2026-07-31）

- 修正照片拖曳到其他欄位後，畫面刷新時排序可能混亂的問題；預設依欄位內手動位置顯示。
- 所有欄位新增右鍵排列方式，可選手動、拍攝時間早到晚／晚到早、檔名遞增／遞減。

## 0.7.6（2026-07-31）

- 修正 PDF／Word／Excel 個別輸出後只開啟檔案、沒有開啟工程輸出資料夾的問題。
- 個別輸出與批次輸出統一依「輸出完成後自動開啟資料夾」設定處理；預覽仍直接開啟預覽檔。

## 0.7.5（2026-07-31）

- PDF 新增三種可選模板：黑白省墨版、清爽藍綠版、暖棕工程版。
- 報告設定可直接預覽目前選擇的 PDF 模板；2／4／6 張照片排列方式維持不變。

## 0.7.4（2026-07-31）

- PDF 每頁 2 張改為上下排列；4 張採 2×2、6 張採 2 欄×3 列，照片格線自動填滿可用頁面空間且不拉伸照片。
- 修正 PDF 固定格線在少量照片或大圖模式時可能多出空白頁的問題。
- 報告設定視窗新增 PDF、Word、Excel 個別「預覽」與「輸出」按鈕，可不關閉設定視窗直接操作單一格式。

## 0.7.3（2026-07-31）

- 新增工程項目與照片欄位改為批次輸入，一次可輸入最多 10 個名稱。
- 依上到下順序建立，空白名稱自動略過，不會產生空白項目／欄位。

## 0.7.2（2026-07-31）

- 未分類照片新增右鍵排序，可依拍攝時間早到晚／晚到早，或檔名遞增／遞減排列。
- 保留未分類日期分隔線；時間排序時沒有拍攝時間的照片會排在最後。

## 0.7.1（2026-07-28）

- PDF 輸出新增每頁照片數設定，可選 1、2、4 或 6 張。
- PDF 照片格線依選定張數自動調整，圖片保持比例縮放，不變形且不覆蓋文字。

- 復原已刪除照片（工具列「復原刪除」）
- Ctrl+Z 復原上一步拖曳／刪除操作（最多 20 步）
- AI 分類讀取項目描述與欄位說明，提升分類準確度

- AI 分類加入使用者已確認的 few-shot 範例

- 開啟工程時自動重建缺少的縮圖
- 修復拖曳照片到頁籤無法跨欄位移動的問題（setAcceptDrops）
- 修復 EXE 打包後 SSL 憑證缺失導致 HTTPS 失敗
