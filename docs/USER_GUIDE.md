# 工程照片整理器使用說明

## 快速流程

1. 點選「新增工程」，填寫工程名稱與基本資料。
2. 在左側按「新增項目」可一次輸入最多 10 個工程項目；按上到下順序建立，留白欄位會略過。也可重新命名或拖曳排序工程項目。
3. 點選「匯入照片」，照片會先進入「未分類」。
4. 選取一張或多張照片，拖到目標項目／欄位；也可以直接拖到目標欄位的頁籤；Ctrl 拖曳代表複製。
5. 選取照片後，在右側修改說明、施工位置，並使用「左轉 90°」「右轉 90°」或「還原旋轉」。
6. 按「馬賽克遮蔽／塗抹」，可調整筆刷大小與輕／中／重模糊力度，選擇筆刷、方形框選、圓形框選或手動描邊人臉、車牌等區域；預設建立馬賽克副本並保留原版，也可直接套用目前照片。
7. 若已設定視覺 API 與視覺模型，按「自動分類」會分析未分類照片。信心度達門檻且能對應到既有項目／欄位的照片會先自動放入建議位置；低信心或無法對應的照片留在未分類，讓你在確認視窗或主畫面拖曳修正。接受舊建議不會覆蓋你已手動移動的照片。
8. 點選「報告輸出」，勾選 PDF、Word、Excel 任一或多種格式。
9. 輸出完成後程式會顯示完整路徑，並可自動開啟工程專屬輸出資料夾；若檔名相同，會自動加上 `_1`、`_2`，不會覆蓋舊檔。

工程資料模板：在「工程基本資料」視窗下方可看到 5 組記憶模板。可先選擇模板位置並修改名稱，按「儲存目前資料」記錄常用的業主、公司、地點、日期與說明；下次開啟任何工程資料視窗時，選擇模板後按「套用模板」即可切換帶入。

照片屬性右側的預覽圖可直接點擊檢視；檢視視窗預設完整顯示全圖，可用按鈕自行放大縮小，放大後按住滑鼠左鍵即可拖曳平移細看。

欄位操作：所有欄位最右側外部只有一個「＋」；按下後可一次輸入最多 10 個欄位名稱，依上到下順序新增，留白欄位會略過。在欄位頁籤上按右鍵可刪除欄位，欄位內照片會回到未分類。未分類、項目照片與各欄位照片都可用 Delete 或右鍵「刪除照片」從工程移除，原始檔仍保留在工程 `originals` 資料夾。

照片排序：拖曳時紅色插入線表示放置位置。報告輸出時依目前欄位由左至右、由上至下排列。未分類及其他欄位都可按右鍵選擇手動排序、拍攝時間由早到晚／由晚到早，或原始檔名遞增／遞減；時間排序時沒有拍攝時間的照片會排在最後，日期分隔線只在未分類區顯示。

照片編號：在右側照片屬性按「為目前欄位生成編號」，可選編號位置（右上、左上、右下、左下）、顏色、自訂像素大小及透明底；透明底會只顯示有顏色的數字。編號只作用於目前頁籤欄位，不會影響其他欄位，按「取消目前欄位編號」即可清除。

照片載入：匯入或拖放大量照片時，畫面會顯示「照片載入中」及目前進度；程式會優先使用快速縮圖，避免使用者誤以為匯入失敗而重複操作。照片可單張或多張拖曳到其他欄位。

PDF 版面：第 1 頁是工程基本資料封面，會以較大的標題與資料表呈現；照片從第 2 頁開始，依工程項目分成第 1 章、第 2 章等章節。輸出時可選擇每頁 1、2、4 或 6 張照片：2 張固定上下排列，4 張採 2×2，6 張採 2 欄×3 列；程式會自動利用可用頁面空間並保持圖片比例。PDF 模板可選黑白省墨版、清爽藍綠版或暖棕工程版，按「預覽目前模板」即可先查看樣式。報告設定完成後，也可使用各格式旁的「預覽」或「輸出」按鈕，單獨處理 PDF、Word 或 Excel。勾選「輸出完成後自動開啟資料夾」時，批次或單獨輸出完成會開啟工程專屬輸出資料夾；預覽則開啟預覽檔。頁尾會顯示工程名稱與頁碼。

## 設定說明

- 預設工程位置：新增工程視窗預設開啟的資料夾。
- 固定報告輸出位置：每個工程會在此位置建立同名子資料夾。
- 照片時間戳：控制報告與 Excel 清冊是否顯示拍攝日期；不會改寫原始照片。
- 輸出原始檔名：控制 PDF、Word 與 Excel 是否顯示原始照片檔名；關閉後輸出內容不列出檔名。
- 空白工程資料：未填寫的工程基本資料不會在 PDF／Word 封面寫入「未填寫」或空白欄位。
- API 設定：可建立多組 OpenAI 相容 API 設定，選取目前使用設定，並以 `/models` 測試連通性。視覺模型建議填 `gemini-3.1-flash-lite`；Google OpenAI-compatible Base URL 為 `https://generativelanguage.googleapis.com/v1beta/openai/`。

API Key 會保存於本機使用者設定檔，請勿將設定檔分享給他人。

AI 自動放置規則：目前以信心度 55% 作為自動放置門檻，且 AI 回傳的項目名稱與欄位名稱必須能對應到工程中已建立的欄位。符合條件會先放入該欄位但保持「待人工確認」；低於門檻、無法對應或辨識失敗的照片會留在未分類。

## 照片編輯原則

旋轉、馬賽克資料與報告用衍生圖會放在工程資料夾的 `edits` 目錄；`originals` 內的原始照片不會被修改。
