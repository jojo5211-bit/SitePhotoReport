# Android 手機版使用指南

## 適用情境

手機版適合在工地直接拍照、匯入相簿、把照片放入項目／欄位、調整順序、生成編號並先預覽 PDF。回到辦公室後，可再用 Windows 桌面版處理大量照片、Word 與 Excel 清冊。

## 首頁與專案管理

首頁直接進入專案管理，可以：

- 建立新工程。
- 開啟最近工程。
- 查看全部工程。
- 備份工程。
- 還原備份。
- 刪除或復原刪除的工程。

刪除前會顯示確認；備份檔請放在不會被手機清理的資料夾或雲端空間。

## 欄位與照片

先建立工程基本資料，再建立項目和照片欄位。欄位上下順序就是報告章節的順序。照片頁支援拍照／匯入、單張或多張選取、跨欄位移動與手動排序。

未分類照片會優先使用 EXIF `DateTimeOriginal`，其次使用其他 EXIF 日期；有日期的照片由早到晚排列，跨日會有日期分隔線，無日期照片排在最後。後續新增照片也會重新依目前排序規則插入。

## 編號與照片編輯

欄位工具列可設定編號的位置、顏色、大小與透明底；「取消目前欄位編號」只作用於目前欄位。照片檢視支援完整顯示、放大、縮小與平移。馬賽克編輯器可使用筆刷、方形、圓形或描邊，並保存原版與編輯版的選擇。

## PDF 預覽與輸出

PDF 預覽會顯示載入狀態，封面包含有填寫的工程資料，後續以項目／欄位為章節。可選模板、每頁照片數、是否顯示編號／日期／檔名與照片說明。輸出完成後可選擇開啟、分享或交由手機其他應用程式處理。

```powershell
flutter analyze
flutter test
flutter build apk --release
```
